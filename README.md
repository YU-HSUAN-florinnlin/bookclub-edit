讀書會 Zoom 錄影的隱私處理工具：把學員的聲音跟姓名去識別化，老師原音保留。**在自己電腦上跑，影片、名冊、成品都留在本機**，不進這個公開倉庫；轉文字會把聲音送到 Groq、分析時會把逐字稿送到 Claude（見「隱私與授權」）。

## 1. 這是什麼

一句話：半自動工具，把讀書會影片裡的學員聲音換成 AI 合成聲線、學員姓名換成代號，老師的部分照樣保留。

目前完成到哪一步：

- **流程第 1 步「影片分析」已經做完並實跑驗證過**：轉文字 → 段落分析（Claude 看文字）、建議刪除段落（另一個 Claude 呼叫）與認老師（聲紋）同時跑 → 冥想引導、導讀整段算老師 → 找出誰跟誰重疊講話 → 自動挑老師參考音 → 找出學員姓名候選 → 學員段落整段認人。可以用 `bookclub run analyze` 一次跑完（見下面「怎麼用」）。
- 本機網頁（`bookclub serve`）目前這幾頁真的能用：
  - 總覽：選影片（按「開始分析」才在影片旁邊建這支影片的工作資料夾）、切換已有的專案
  - 第 0 步「初始化設定」：看共用設定、匯出／匯入設定包給夥伴
  - 第 1 步進度頁（各子步驟完成狀態、耗時）
  - 第 2 步「挑選老師參考聲音片段」：確認老師的參考音、修逐字稿、選定
  - 第 3 步「覆核工作台」（測試版）：先做開始前 4 件事，再邊看影片邊逐筆按「通過」（每一筆都已經有建議）；漏抓的用「＋新增修改」補（時間自動對齊）；匯出覆核結果交給夥伴
  - 第 4 步「AI 執行」（測試版）：先過「開始前總檢查」，再按「開始執行」依序跑老師名字 → 學員重念 → 保留原聲學員講到名字 → 組裝，做過的跳過；第 5 步退回的按「只重做退回的這幾筆」
  - 第 5 步「成品檢查」（測試版）：逐筆聽處理前後、整片看完 100%，有問題退回 AI 重做；全部通過才能輸出
  - 左側步驟列每一步標「AI」或「人工」，可以收合（記得上次的狀態）

流程（09-29 改成 0～5：原本第 5 步逐筆覆核、第 6 步整片檢查合成第 5 步「成品檢查」）：

| 步驟 | 誰做 | 內容 |
| --- | --- | --- |
| 0　初始化設定 | 人工（跨專案共用，做一次） | 名冊、敏感詞、名字排除清單、發音對照表、匿名聲線；可以匯出設定包給夥伴 |
| 1　影片分析 | AI | 轉文字、段落分析、認老師、找重疊、挑參考音、找名字、學員認人 |
| 2　挑選老師參考聲音片段 | 人工 | 聽推薦的一段、改逐字稿到一字不差 |
| 3　覆核工作台 | 人工 | 開始前 4 件事（建議刪除段落、學員是誰、名冊上沒有的名字、誰保留原聲），再邊看影片邊逐筆通過；漏抓的用「＋新增修改」補 |
| 4　AI 執行 | AI | 換聲音、刪除與停格，寫 AI 處理紀錄並自動檢查有沒有沒登記的變動 |
| 5　成品檢查 | 人工 | 逐筆聽處理前後、整片看完（看過 100% 才能輸出），有問題退回 AI 重做 |

**還沒做的部分**：畫面處理（找學員的臉與姓名標籤；這一版不處理畫面，`render video` 的模糊只是固定位置的示範，正式成品不加）；片頭、片尾自動接上；Windows 的啟動捷徑；重疊「兩邊都重新生成、前後排開」（「照原本的時間」已經做好）；第 5 步寫的退回原因還不會交給 AI 參考（退回的那幾筆一鍵重做已經做好，見第 5 步）；匯入老師自己的標記清單（還沒確認老師標記是什麼形式）；`bookclub export`／`bookclub bench` 指令還沒做。消音的「聲音霧化」還沒做（選了先墊底噪）。這些與已知的小問題、移植到 Windows 要注意的地方，列在 [`docs/之後要做.md`](docs/之後要做.md)。


## 2. 這一版能做到什麼

第 1 步全部分析（逐字稿、每一句是誰說的、聲音重疊、老師參考音候選、姓名候選、建議刪除段落）；網頁上確認參考音、在覆核工作台逐筆決定怎麼處理；第 4 步生成老師名字與學員重念、組出處理過的影片（刪除、停格、局部消音）；第 5 步逐筆與整片檢查後輸出成品。

**這一版只處理聲音與說出口的名字，不處理畫面**：學員的臉、Zoom 畫面上的姓名標籤都會留在成品裡。成品要給別人看之前，畫面請另外處理。

適合拿來測的：從安裝到輸出成品整條走一次；轉文字漏掉的地方、名字有沒有漏、學員重念聽起來自然不自然、第 5 步標出來要人聽的地方；每一步實際花多久。

## 3. 準備什麼

第一次安裝前，照順序準備好這幾樣（打 ✱ 的是 WSL2 才要做的）。Windows 還沒裝過 WSL2 的話，先照第 4 節「Windows：第一次安裝 WSL2 與 Ubuntu」裝好（下面第 2、3 項，那一節也有一步一步的寫法）；不熟電腦的話，可以照第 4 節「用 Claude 桌面版帶著安裝與啟動（Windows）」請 Claude 一步一步帶著做。

| # | 要準備的 | 做什麼用 | 怎麼準備 |
| --- | --- | --- | --- |
| 1 | 硬碟空間 | 模型、套件、工作區 | 至少 15GB（模型約 7GB、套件約 3GB；WSL2 用只用處理器的 torch）；每支 2 小時影片的工作區另外抓 5–10GB |
| 2 | ✱ WSL2 記憶體上限 | 找重疊、組裝整支影片 | WSL2 預設只能用主機一半的記憶體。在 Windows 使用者資料夾建 `.wslconfig`：16GB 的電腦寫 `[wsl2]`、`memory=10GB`、`swap=8GB`（推估，還沒實測）；32GB 的電腦寫 `memory=24GB`、`swap=16GB`。存檔後在 PowerShell 跑 `wsl --shutdown` 再開（怎麼建、依據、其他記憶體大小怎麼辦，見「Windows：第一次安裝 WSL2 與 Ubuntu」第 7 步） |
| 3 | Groq API 金鑰 | 語音轉文字（免費額度通常夠） | 到 [console.groq.com](https://console.groq.com) 申請。把 `export GROQ_API_KEY=你的金鑰` 加進：**macOS → `~/.zshrc`**；**WSL2 → `~/.profile`**（不要放 `~/.bashrc`：Ubuntu 的 `.bashrc` 在非互動模式會提早結束，工具讀不到）。加完開新的終端機視窗（WSL2 的一行指令寫法見「Windows：第一次安裝 WSL2 與 Ubuntu」第 9 步）。**金鑰不要寫進其他檔案、也不要貼給 AI** |
| 4 | Hugging Face 帳號與同意條款 | 分辨誰在說話（pyannote 是要先同意條款的模型） | ① 註冊／登入 [huggingface.co](https://huggingface.co) ② 打開 [pyannote/segmentation-3.0](https://huggingface.co/pyannote/segmentation-3.0) 與 [pyannote/speaker-diarization-3.1](https://huggingface.co/pyannote/speaker-diarization-3.1) 各按一次同意 ③ Settings → Access Tokens 建一把 **Read** 金鑰。登入指令在安裝完之後跑（見下一節） |
| 5 | Claude Code（登入過） | 段落分析、建議刪除段落、人名清單（第 1 步） | macOS 裝好 Claude Code 即可。**✱ WSL2 要在 WSL2 裡面另外裝一份**（Windows 那份 WSL2 用不到）：`curl -fsSL https://claude.ai/install.sh \| bash`，裝完執行 `claude` 登入一次。沒裝的話第 1 步會跳過段落分析，第 3 步沒有學員段落可以覆核 |
| 6 | 設定包（向開發者拿） | 名冊、敏感詞、名字排除清單、發音對照表、**匿名聲線**（學員重念用的男聲、女聲） | 安裝完用 `bookclub profile import 設定包.zip` 匯入（見「怎麼用」第 0 步）。沒有設定包時，安裝會放範例檔，名冊要自己填、匿名聲線要另外準備 |
| 7 | 影片檔 | 讀書會的 Zoom 錄影（.mp4） | 放進 `~/讀書會剪輯資料/影片/`（安裝時會建好這個資料夾）。工作區會建在影片旁邊，所以影片放哪裡，工作區就在哪裡。**✱ WSL2 一定要先把影片複製進 WSL2 自己的資料夾**，不要直接用 `/mnt/c/...` 底下的檔案：網頁只能選家目錄底下的檔案，跨系統讀寫也慢很多。怎麼複製進去、成品怎麼拿回 Windows，見下面「WSL2：影片放進去、成品拿出來」 |

名冊欄位：`中文名`（學員本名）、`其他寫法`（同音字、暱稱、轉文字常聽錯的寫法，多個用「、」分隔）、`性別`（決定用男聲或女聲重念）。**代號不寫在名冊**：每一集在第 3 步選（代號是外國人名的中文寫法，例如「潔西」；同一集同一人同一個代號就好）。敏感詞欄位：`原詞`、`替代詞`。這幾份含真實姓名，放在 `~/讀書會剪輯資料/`，不要提交進任何 git 倉庫。

### WSL2：影片放進去、成品拿出來

WSL2 的 Ubuntu 有自己的檔案系統，Windows 的 C 槽在 WSL2 裡叫 `/mnt/c/`。下面的 `你的Windows使用者名稱` 換成你自己的（在 Windows 檔案總管打開「使用者」資料夾看得到）。這一段還沒在 WSL2 實測。

**把影片從 Windows 複製進 WSL2**（例如影片在 Windows 的「下載」資料夾）：

```bash
cp "/mnt/c/Users/你的Windows使用者名稱/Downloads/第1堂.mp4" ~/讀書會剪輯資料/影片/
```

**把成品拿回 Windows**：第 5 步按「輸出成品」後，成品在影片旁邊的工作區 `輸出/` 底下，檔名開頭是 `最終成品_`：

```bash
cp ~/讀書會剪輯資料/影片/第1堂_剪輯工作區/輸出/最終成品_*.mp4 "/mnt/c/Users/你的Windows使用者名稱/Downloads/"
```

也可以用 Windows 的檔案總管直接開 WSL2 的資料夾，再用拖曳的方式複製：在 WSL2 終端機打下面這行（最後的 `.` 是「目前這個資料夾」）。

```bash
cd ~/讀書會剪輯資料/影片 && explorer.exe .
```

### Windows：跑之前先把電腦設成不睡眠

第 4 步要連續跑好幾個小時（第 1 步也要將近 1 小時）。**電腦一睡眠或休眠，正在跑的步驟就會停下來**，醒來後可能接不上、要再按一次開始（做好的會留著，不用重做）。WSL2 本身沒有防睡眠的功能，要靠 Windows 的電源設定。

跑之前：

1. **先記下現在的設定**（跑完要改回來）。
2. **Windows 11**：開「設定」→「系統」→「電源與電池」（桌上型電腦叫「電源」）→ 展開「螢幕、睡眠與休眠逾時」（較早的 Windows 11 叫「螢幕和睡眠」）。把「接上電源時」的**睡眠**、**休眠**都設成「永不」。螢幕可以照常關掉（關螢幕不會中斷），不放心的話也設成「永不」。
3. **Windows 10**：開「設定」→「系統」→「電源與睡眠」。「睡眠」底下「接上電源時，電腦在下列時間後進入睡眠」設成「永不」。螢幕那一格可以不改。
4. **休眠**（Windows 10 與 11 都一樣，有些電腦看不到這一項就跳過）：開「控制台」→「硬體和音效」→「電源選項」→ 目前使用的計劃旁邊的「變更計劃設定」→「變更進階電源設定」→「睡眠」→「休眠時間」，「接上電源」設成「永不」。
5. **筆電**：一定要**接電源**，而且**不要闔上螢幕**。要闔上的話，到「控制台」→「硬體和音效」→「電源選項」→ 左邊「選擇蓋上螢幕時的行為」，把「接上電源」那一欄的「當我蓋上螢幕時」設成「不執行任何動作」，按「儲存變更」。
6. **Windows Update**：自動更新可能半夜重新開機。跑之前到「設定」→「Windows Update」按「暫停更新」。

以上選項的名稱依 Windows 版本可能略有不同，意思一樣就對了。也可以請 Claude Code 在 Windows 的 PowerShell 用 `powercfg` 指令設定（例如 `powercfg /change standby-timeout-ac 0`、`powercfg /change hibernate-timeout-ac 0` 把接上電源時的睡眠、休眠設成永不）。

**跑完記得改回來**（照第 1 步記下的設定），筆電闔上螢幕的行為也改回原本的，暫停的更新也可以恢復。

**macOS**：第 4 步執行時，工具會自己讓電腦不進入閒置睡眠（用系統內建的 `caffeinate`），做完自動恢復；螢幕可以關。但**闔上筆電螢幕還是會睡**，筆電請接電源、螢幕打開。第 1 步分析時工具不會防睡眠：跑的時候請在「系統設定」把電腦閒置後進入睡眠的時間拉長（位置依 macOS 版本不同，常見在「鎖定畫面」或「電池」→「選項」），跑完再改回來。

### Windows（WSL2）要注意的事

散在這份說明各處、Windows（WSL2）才會遇到的事，集中在這裡：

- **網頁要自己開**：WSL2 不會自動開瀏覽器。在 Ubuntu 的終端機打 `.venv/bin/bookclub serve` 之後，終端機會印「這是 WSL2，不會自動開瀏覽器：請在 Windows 的瀏覽器（Edge 或 Chrome）開 http://localhost:8766/」，照著在 Windows 的瀏覽器開這個網址。
- **關掉那個終端機視窗，網頁就停了**：跑 `bookclub serve` 的終端機視窗要一直開著（可以縮小）。第 4 步跑到一半關掉，下次開網頁會顯示「中斷」，按「開始執行」會接著做。
- **網頁已經開著又開一次**：終端機會說「讀書會剪輯工具已經開著了」，直接用瀏覽器開原本的網址就好；如果是別的程式占用了這個埠，訊息會說怎麼查、怎麼改用別的埠。
- **Groq 金鑰寫在 `~/.profile`**，不要寫在 `~/.bashrc`（寫在裡面工具讀不到）。讀不到金鑰時，新影片的第 1 步不能開始轉文字（已經轉好文字的不受影響）、第 4 步不能開始生成，畫面會說要寫在 `~/.profile`、開新的終端機視窗再啟動。一行指令的寫法見「Windows：第一次安裝 WSL2 與 Ubuntu」第 9 步。
- **第 1 步與第 4 步都要先把電腦設成不睡眠**：WSL2 沒有防睡眠的功能，見「Windows：跑之前先把電腦設成不睡眠」。
- **影片要先複製進 WSL2 自己的資料夾**（`~/讀書會剪輯資料/影片/`），成品再複製回 Windows，見「WSL2：影片放進去、成品拿出來」。網頁只能選家目錄底下的檔案；`/mnt/c/...` 底下的檔案跨系統讀寫也慢很多。
- **中文路徑**：影片、工作區放在 WSL2 自己的資料夾、路徑有中文，還沒在 WSL2 上實測過；直接用掛在 `/mnt/` 底下（Windows 磁碟）的中文路徑更沒有測過，請不要這樣用。遇到跟路徑有關的錯誤請回報。
- **輸出方式只有「標準輸出」**（整段軟體編碼）：第 4 步「進階設定」裡的另外兩種（用 Mac 顯示晶片的硬體編碼、只重做有動到的片段）只有 Mac 才會列出來。標準輸出在 Mac 與 Windows 的結果一樣。
- **`doctor --smoke` 會跳過**：測試用的假錄音要用 Mac 內建的功能產生，Linux／WSL2 上會說「只在 Mac 上跑，這次跳過（不算失敗）」。
- **標字試看版**（終端機 `render video --label`，測試用）在 Windows 上找不到中文字型、做不出來；正式流程（網頁第 4 步）不會用到。
- **記憶體**：WSL2 預設只能用電腦一半的記憶體。16GB、32GB 的電腦怎麼設 `.wslconfig`，見「Windows：第一次安裝 WSL2 與 Ubuntu」第 7 步（16GB 的是推估值）。第 4 步跑的過程中，WSL2 裡可用記憶體低於 1.5 GB、或 swap 超過門檻，工具會請程式做完目前這一句就停（這項只有模擬測試，還沒在實機跑過）。
- **還沒有雙擊就能開的啟動捷徑**：照「怎麼用」在 Ubuntu 的終端機打指令啟動。

### Windows：第一次安裝 WSL2 與 Ubuntu

> 這一節是照微軟官方文件整理的，還沒有在實際的 Windows 電腦上逐步驗過；遇到跟說明不一樣的地方請回報給開發者。

工具在 Windows 上是跑在 WSL2（Windows 裡面的一個 Linux 環境）的 Ubuntu 裡。已經裝好、打得開 Ubuntu 終端機的，直接跳到下面「下載程式」。想請 Claude 帶著做的，見上面「用 Claude 桌面版帶著安裝與啟動（Windows）」。

每一步照「要做什麼 → 會看到什麼 → 看到這個就成功了」寫。畫面上的字依 Windows 版本可能略有不同，意思一樣就對了。

**第 1 步　確認 Windows 版本夠新**

- 要做什麼：按鍵盤的 Windows 鍵，打 `winver`，按 Enter。
- 會看到什麼：一個「關於 Windows」的小視窗，寫著 Windows 10 或 Windows 11，和「版本」「OS 組建」。
- 成功：Windows 11 都可以；Windows 10 要「版本 2004」以上（組建 19041 以上）。比這個舊的，先做 Windows Update 更新，或請開發者協助（官方另有手動安裝的步驟）。

**第 2 步　用系統管理員身分開 PowerShell**

- 要做什麼：按 Windows 鍵，打 `PowerShell`，在「Windows PowerShell」上按滑鼠右鍵，選「以系統管理員身分執行」。
- 會看到什麼：跳出視窗問「要允許此 App 變更您的裝置嗎？」，按「是」。接著出現一個深色（通常是藍色或黑色）的視窗，標題有「系統管理員」。
- 成功：視窗裡有一行閃爍的游標，前面寫著 `PS C:\WINDOWS\system32>` 之類的字。
- 卡住：沒有「是」可以按、要你輸入管理員帳號密碼，代表這台電腦的帳號沒有系統管理員權限（公司或學校的電腦常這樣）。請找電腦的管理者幫忙，或換一台自己的電腦。

**第 3 步　安裝 WSL2 與 Ubuntu**

- 要做什麼：在剛剛的 PowerShell 視窗打下面這行，按 Enter：

  ```powershell
  wsl --install
  ```

- 會看到什麼：一段一段的安裝訊息與進度，最後提示要重新開機。
- 成功：訊息跑完、沒有紅字。這一行會把 WSL2 需要的功能打開，並安裝 Ubuntu。
- 卡住：
  - 只印出一大段 WSL 的說明文字、沒有開始安裝：代表 WSL 已經裝過一部分。改打 `wsl --list --online` 看可以裝哪些，再打 `wsl --install -d Ubuntu`。
  - 進度停在 0.0% 不動：改打 `wsl --install --web-download -d Ubuntu`。

**第 4 步　重新開機**

- 要做什麼：存好其他檔案，重新開機。
- 成功：重開後回到桌面。有時 Ubuntu 的視窗會自己跳出來，就直接做第 5 步。

**第 5 步　第一次打開 Ubuntu，設定使用者名稱與密碼**

- 要做什麼：Ubuntu 視窗沒有自己跳出來的話，按 Windows 鍵，打 `Ubuntu`，點開。
- 會看到什麼：第一次開要等它解壓縮、安裝一下（之後再開就很快）。接著問您要用的使用者名稱（英文小寫，例如 `teacher`），再問兩次密碼。
- **打密碼時畫面上不會出現任何字**（連星號都沒有），這是正常的，打完按 Enter 就好。
- **這組密碼請記下來**：之後安裝工具時，畫面跳出 `[sudo] password for …` 要的就是這組密碼。它跟 Windows 的登入密碼是兩回事。
- 成功：最後出現一行類似 `teacher@電腦名稱:~$` 的字，後面有閃爍的游標。這就是「Ubuntu 的終端機」，這份說明裡的 `bash` 指令都打在這裡。

**第 6 步　之後怎麼再打開 Ubuntu 的終端機**

- 按 Windows 鍵，打 `Ubuntu`，點開。也可以在「Windows 終端機」（Windows Terminal）的分頁選單裡選 Ubuntu。
- 找不到 Ubuntu：開 PowerShell 打 `wsl --list --verbose`，看清單裡有沒有 Ubuntu、`VERSION` 是不是 2。清單是空的，回到第 3 步。在 PowerShell 打 `wsl` 也可以直接進到 Ubuntu。
- 在 Ubuntu 終端機貼上文字：按滑鼠右鍵，或按 `Ctrl＋Shift＋V`（依視窗不同可能略有差異）。

**第 7 步　設定 WSL2 可以用的記憶體（16GB、32GB 的電腦）**

先看電腦有多少記憶體：「設定」→「系統」→「關於」，「已安裝的 RAM」那一行（名稱可能略有不同）。

| 電腦記憶體 | memory | swap | 依據 |
| --- | --- | --- | --- |
| 16GB | `10GB` | `8GB` | **推估，還沒有在 16GB 的 Windows 電腦上實測**。理由見下面 |
| 32GB | `24GB` | `16GB` | 這份說明原本的建議值；也還沒實測過這組設定（09-29 在 WSL2 實測時，WSL2 分到的是約 15GB，跑得完第 1 步） |
| 其他 | 先不要設 | 先不要設 | 還沒有建議值：用預設值，裝完跑 `bookclub doctor` 看「記憶體」那一項，把結果回報給開發者 |

**16GB 為什麼建議 10GB／8GB**（三個依據）：

1. **WSL2 不設定時的預設值**：微軟官方〈WSL 中的進階設定組態〉（<https://learn.microsoft.com/zh-tw/windows/wsl/wsl-config>）的 `.wslconfig` 設定表寫，`memory` 預設是「Windows 上總記憶體的 50%」，`swap` 預設是「Windows 上 25% 的記憶體大小四捨五入至最接近的 GB」。16GB 的電腦不設定，WSL2 只拿得到約 8GB、swap 約 4GB。
2. **工具自己的門檻**：
   - `bookclub doctor` 與 `install.sh` 看到 WSL2 裡的記憶體低於 8GB 會提醒（`bookclub/doctor.py` 的 `check_memory`、`install.sh` 的系統檢查）。預設的「一半」剛好落在 8GB 邊緣，WSL2 裡實際讀到的總量通常比設定的再少一點。
   - 第 4 步在 Linux／WSL2 上，可用記憶體低於 **1.5 GB** 就請程式做完目前這一句停下來（`bookclub/execute.py` 的 `MIN_AVAILABLE_GB`）；開始前的檢查估計載入模型會用掉約 **5 GB**（同一個檔的 `MEM_LOAD_GB`），可用記憶體扣掉 5 GB 低於 1.5 GB 就提醒「偏滿」。也就是開始前 WSL2 裡最好有 6.5 GB 以上可以用。
   - swap 用量超過 **8.5 GB** 也會停（`settings.toml` 的 `execute_max_swap_gb`，預設值在 `bookclub/config.py`）。
3. **已有的實測**：8GB 記憶體的 M1 Mac 跑得完第 4 步（Mac 會自己拿硬碟頂替記憶體）；聲音生成模型約 4.4 GB、逐字對位模型約 1.7 GB，現在一次只載入一個（CHANGELOG 0.2.0b1「第 4 步每一步、每一個聲線各自一支程式跑」）；組裝 98 分鐘的整支影片，記憶體高峰 3.9 GB（CHANGELOG 0.2.0b1「組裝分段處理」）。Windows＋WSL2 那台電腦（WSL2 分到約 15GB）09-29 跑得完第 1 步（見「速度參考」）。

所以 16GB 的電腦給 WSL2 **10GB**：比預設多 2GB，載入最大的模型（約 4.4 GB）之後還留得下 1.5 GB 以上，`doctor` 也不會提醒；Windows 自己與瀏覽器還留約 6GB。swap 給 **8GB**：比預設的 4GB 多，記憶體一時不夠時有地方頂替，又不會超過 8.5 GB 的停止門檻。

**第一次跑完，請回報給開發者兩件事**：第 4 步有沒有被自動停下來（畫面上「已停止」後面會寫原因）、第 4 步花了多久。Windows 在第 4 步跑的時候變得很卡，也請一起說。

設定的方法：

- 要做什麼：開一般的 PowerShell（不用系統管理員），打下面其中一行（照您電腦的記憶體選），按 Enter。它會在 Windows 使用者資料夾（`C:\Users\你的Windows使用者名稱\`）建一個叫 `.wslconfig` 的檔案。**已經有這個檔案的話先不要打**（會蓋掉原本的內容），請開發者協助。

  16GB 的電腦：

  ```powershell
  Set-Content -Path "$env:USERPROFILE\.wslconfig" -Value "[wsl2]`nmemory=10GB`nswap=8GB"
  ```

  32GB 的電腦：

  ```powershell
  Set-Content -Path "$env:USERPROFILE\.wslconfig" -Value "[wsl2]`nmemory=24GB`nswap=16GB"
  ```

  用指令建，是為了避開「記事本存檔時自動在檔名後面加 `.txt`」的問題：檔名變成 `.wslconfig.txt`，WSL2 就讀不到。
- 確認檔案：打 `Get-Content "$env:USERPROFILE\.wslconfig"`，看到三行（`[wsl2]`、`memory=…`、`swap=…`）就對了。
- 讓設定生效：關掉所有 Ubuntu 視窗，在 PowerShell 打 `wsl --shutdown`，等大約 10 秒再打開 Ubuntu。
- 確認設定有生效：在 Ubuntu 終端機打 `free -h`。`Mem:` 那一行的 `total` 會接近您設的 memory（通常會比設的數字少一點），`Swap:` 那一行的 `total` 會接近您設的 swap。如果還是約電腦記憶體的一半，代表設定沒有生效：確認檔名不是 `.wslconfig.txt`，再做一次 `wsl --shutdown`。
- 官方也提供「WSL 設定」程式（在開始功能表找），可以不改檔案、直接在畫面上設記憶體。

**第 8 步　Windows 的檔案在 Ubuntu 裡在哪裡**

- Windows 的 C 槽，在 Ubuntu 裡是 `/mnt/c/`。例如 Windows 的「下載」資料夾是 `/mnt/c/Users/你的Windows使用者名稱/Downloads/`。
- 工具和影片都要放在 Ubuntu 自己的資料夾（`~` 底下），不要放在 `/mnt/c/...`：跨系統讀寫慢很多，網頁也只能選家目錄底下的檔案。怎麼把影片複製進來、成品怎麼拿回 Windows，見上面「WSL2：影片放進去、成品拿出來」。
- 想用 Windows 的檔案總管看 Ubuntu 的資料夾：在 Ubuntu 終端機打 `explorer.exe .`（最後有一個點）。

**第 9 步　把轉文字服務（Groq）的金鑰寫進 `~/.profile`**

- 要做什麼：在 Ubuntu 終端機打下面這行（`你的金鑰` 換成在 console.groq.com 申請到的那一串，前後的單引號要留著），按 Enter：

  ```bash
  echo 'export GROQ_API_KEY=你的金鑰' >> ~/.profile
  ```

  這行是把一行字加到 `~/.profile` 的最後面，不用學編輯器。**`>>` 是兩個大於符號**（只打一個會把整個檔案蓋掉）。
- 確認：打 `grep -c GROQ_API_KEY ~/.profile`，印出 `1` 就對了（印出 2 以上代表加了好幾次，請開發者協助整理）。
- 讓設定生效：關掉這個 Ubuntu 視窗，重新打開一個。
- 為什麼不能放 `~/.bashrc`：Ubuntu 的 `~/.bashrc` 一開頭就判斷「不是互動模式就結束」，工具在背景執行時讀不到寫在裡面的金鑰；`~/.profile` 才讀得到（`bookclub doctor` 檢查的也是這個檔）。
- 金鑰不要貼給 AI、不要寫進其他檔案。

**第 10 步　接著做：下載程式、安裝**

- 照下面「下載程式」「先檢查電腦裡已經有什麼」「正式安裝」做。打 `git clone` 時如果說找不到 `git`，先打 `sudo apt-get update && sudo apt-get install -y git`（會問第 5 步設的密碼）。
- 安裝完，照「裝完之後」登入 Hugging Face：`hf auth login` 會出現 `Enter your token (input will not be visible):`，**貼上金鑰時畫面一樣不會顯示任何字**，貼上後按 Enter。接著問 `Add token as git credential?`，打 `n` 按 Enter。
- 第 3 節「準備什麼」第 5 項的 Claude Code，要在這個 Ubuntu 終端機裡另外裝一份。

**常見卡住的地方**

- **跟虛擬化有關的錯誤**（例如出現 `0x80370102`、「無法啟動虛擬機器」）：電腦的 BIOS（開機時的設定畫面）要打開「虛擬化」。每台電腦進入 BIOS 的方式與選項名稱都不一樣，多半在處理器（CPU）相關的選項裡；可以先在「工作管理員」→「效能」→「CPU」看「虛擬化」是不是「已啟用」。這一步建議請熟電腦的人協助。
- **沒有系統管理員權限**（公司、學校的電腦）：第 2 步做不下去，請電腦的管理者協助。
- **Windows 版本太舊**：先做 Windows Update；Windows 10 版本 2004 以前的要照官方的手動安裝步驟，請開發者協助。
- **Ubuntu 視窗找不到**：見第 6 步。

### 正式安裝

```bash
cd ~/bookclub-edit
bash install.sh
```

同一份腳本在 **macOS** 與 **Linux（含 Windows 的 WSL2 Ubuntu）** 都能跑，會自己判斷平台：macOS 用 Homebrew，Linux 用 apt-get 安裝 ffmpeg、sox、git、build-essential、curl、unzip，`uv` 用官方安裝指令。Linux 安裝系統套件那一步需要系統管理員權限，畫面上會跳出密碼提示。不是 Debian／Ubuntu 系統的話，腳本會列出需要的套件請你自行安裝。

`install.sh` 會依序做：檢查系統與空間 → 裝 Homebrew 套件（ffmpeg、uv）→ 建立 Python 3.11 虛擬環境（`.venv/`）→ 裝 Python 套件與 `bookclub` 指令 → 抓聲音生成引擎 CosyVoice 原始碼 → 下載三個 AI 模型 → 建立 `~/讀書會剪輯資料/` 資料夾（並複製 `profile.example/` 的範例檔進去）→ 建 Claude Code 的 skill 捷徑 → 跑一次環境健檢。**可以重複執行**：已經做過的步驟會自動跳過，不會重複下載，也不會刪掉已經調整過的設定。第一次安裝依網路速度可能要半小時以上，大部分時間花在下載模型。

**WSL2**：2026-09-29 用 0.1.8 在 Windows 11＋WSL2（Ubuntu 26.04）實測，4 分半全自動裝完、中間不用人介入。沒有 NVIDIA 顯示卡時，腳本會裝只用處理器的 torch（CUDA 版多下載約 2.8GB 用不到的套件）；**這一段是 0.1.8 之後才加的，還沒在真的 WSL2 上跑過**，第一次安裝就是它的第一次實測，出錯請把畫面上的訊息回報。`uv` 裝完如果找不到，開新終端機再重跑。ModelScope 限流時（`[403] 操作过于频繁`）腳本會重試後先略過，下一步 `models download` 會補上。

### 更新到新版本

每出一個新版本，請把程式**整個重新下載一次**，不要在舊的工具資料夾上更新。做法是：舊的工具資料夾改名留著 → 重新下載一份到原本的位置 → 再跑一次安裝。新版的變動寫在 [`CHANGELOG.md`](CHANGELOG.md)。

**不會受影響的**（都不在工具資料夾裡）：

- 設定與資料 `~/讀書會剪輯資料/`：名冊、敏感詞、名字排除清單、發音對照表、匿名聲線、`settings.toml`、專案清單（網頁「總覽」列的專案）
- 每支影片的工作區：影片旁邊的 `<影片檔名>_剪輯工作區/`，做到一半的照樣接著做
- AI 模型：`~/.cache/bookclub/`（聲音生成，約 5GB）、`~/.cache/huggingface/`（逐字對位）、`~/.cache/torch/pyannote/`（分辨誰在說話）。安裝時會認出已經下載好的，不會重新下載
- 各種登入與金鑰：Hugging Face 登入、Groq 金鑰（`~/.zshrc` 或 `~/.profile`）、Claude Code 登入，都不用重做

**會重新做的**（都在工具資料夾裡）：

- 程式本身
- Python 執行環境 `.venv/`（Mac 上約 1.3GB）：重新建立、重新裝套件。套件第一次安裝時已經下載過，會留在 `~/.cache/uv/`，重裝時大多直接從這裡拿，不用再從網路下載
- 聲音生成引擎的原始碼 `third_party/CosyVoice/`（約 10MB，重新從 GitHub 抓）

**大概多久**：2026-09-29 在 WSL2 第一次安裝（套件全部要下載、模型沿用）花 4 分半。重新下載時套件多半已經在電腦裡，應該會比這個快，但還沒實測過。舊的工具資料夾刪掉之前，硬碟要多留約 2GB。

**步驟**（macOS 與 WSL2 一樣，差別寫在步驟裡）：

1. **停掉網頁**：第 4 步正在跑的話，先按「停止」，等它停下來。再到跑網頁的那個終端機視窗按 `Ctrl＋C`（macOS 是雙擊「啟動.command」開出來的那個視窗）。
2. **確認沒有上一次留下的舊版資料夾**：家目錄底下如果還有 `bookclub-edit-舊版`，先照第 7 步刪掉。
3. **舊的工具資料夾改名留著**（新版有問題時還可以改回來）：

   ```bash
   cd ~
   mv bookclub-edit bookclub-edit-舊版
   ```

4. **重新下載**，放回原本的位置（位置不變，Claude Code 的 skill 捷徑才會繼續指到對的地方）：

   ```bash
   cd ~
   git clone https://github.com/YU-HSUAN-florinnlin/bookclub-edit.git
   ```

5. **安裝**：

   ```bash
   cd ~/bookclub-edit
   bash install.sh
   ```

   最後會自動跑一次環境健檢，第一行印出現在的工具版本，確認是新的版本號；必要項目要全部 ✅。WSL2 如果畫面跳出密碼提示，輸入 Ubuntu 的登入密碼。
6. **開網頁確認**：macOS 雙擊工具資料夾裡的「啟動.command」；WSL2 打下面兩行，再用 Windows 的瀏覽器開 <http://localhost:8766>：

   ```bash
   cd ~/bookclub-edit
   .venv/bin/bookclub serve
   ```

   「總覽」看得到原本的專案、第 0 步的名冊筆數跟以前一樣，就是設定與資料都接上了。
7. **用過一陣子確定新版沒問題，再刪掉舊版資料夾**：macOS 在 Finder 把家目錄底下的 `bookclub-edit-舊版` 丟到垃圾桶；WSL2 打下面這行（刪了就救不回來，確認名字是 `bookclub-edit-舊版` 再按 Enter）：

   ```bash
   rm -rf ~/bookclub-edit-舊版
   ```

**新版有問題、想先回到舊版**：停掉網頁，把新的改名、舊的改回來，再照第 6 步開網頁：

```bash
cd ~
mv bookclub-edit bookclub-edit-新版有問題
mv bookclub-edit-舊版 bookclub-edit
```

新版本改過工作區的檔案格式時，回到舊版可能讀不懂新版存過的工作區；會不會這樣，看 `CHANGELOG.md` 那一版的說明。

## 5. 怎麼用

**平常操作都在網頁上**：

1. 開網頁：
   - macOS：雙擊工具資料夾裡的「啟動.command」，瀏覽器會自動開 <http://localhost:8766>
   - WSL2：在 Ubuntu 的終端機打下面兩行，再用 Windows 的瀏覽器（Edge 或 Chrome）開 <http://localhost:8766>（WSL2 不會自動開瀏覽器，終端機會印出網址；這個終端機視窗要開著，關掉網頁就停了）。網頁在 WSL2 上還沒實測

     ```bash
     cd ~/bookclub-edit
     .venv/bin/bookclub serve
     ```

   伺服器記得上次在做哪支影片，重開後自動接回
2. 「總覽」選影片、按「開始分析」（在影片旁邊建 `<影片檔名>_剪輯工作區/`；做到一半的會接著做）。網頁只能選家目錄底下的影片
3. 照左側步驟列走：0 初始化設定（人工，第一次才要）→ 1 影片分析（AI）→ 2 挑選老師參考聲音片段（人工）→ 3 覆核工作台（人工：先做開始前 4 件事，再逐筆通過）→ 4 AI 執行（AI：可以按「停止」，下次接著做；跑的時候第 3 步只能看不能改）→ 5 成品檢查（人工：全部通過、整片看過 100% 才能輸出）
4. 存檔失敗時（例如伺服器被關掉），畫面最上面會出現紅色橫幅，重新整理再改一次；網頁連續連不上伺服器時，也會出橫幅「連不上伺服器，可能已經關掉了」

### 時間怎麼抓

**第一次處理一支影片，請預留 12 小時**（從開始到全部做完，含中間的人工步驟）。下面是一支約 97 分鐘影片的參考：

| 步驟 | 誰做 | 大約多久 | 人可以離開嗎 |
| --- | --- | --- | --- |
| 1 影片分析 | 電腦 | 約 45 分鐘（8GB 的 M1 Mac 實測，2026-10-04；其中找重疊約 27 分鐘） | 可以，電腦不要睡眠 |
| 2 挑老師參考音 | 人 | 依人而定（聽幾段候選、把逐字稿改到一字不差） | 不行 |
| 3 覆核工作台 | 人 | 依影片而定，通常是最花人工的一步；頂端會推算整支要多久 | 不行（可以分好幾次做，存檔會留著） |
| 4 AI 執行 | 電腦 | 約 3–4 小時（M1 上的推估） | 可以，電腦不要睡眠、不要拿來做別的事 |
| 5 成品檢查 | 人 | 至少整支影片的長度（整片要看過 100%），加上逐筆聽 | 不行 |

- 老師與夥伴的 Windows 電腦還沒有跑過這一版，沒有數字；Mac 與 Windows 目前都只用處理器在算（沒有用到顯示卡）。09-29 實測，WSL2 那台電腦生成聲音比 M1 快 3–5 倍、找重疊比 M1 慢（見「速度參考」）。
- 第 4 步跑的時候，同時開著別的程式會慢三倍以上，記憶體不夠還可能中途停下來。適合晚上睡前按下去。
- 跑第 1、4 步之前，先照「Windows：跑之前先把電腦設成不睡眠」設好（Mac 見同一節最後一段）。

### 每一步要特別注意的

- **第 3 步做過之後，不要為了重跑第 1 步去改名或刪掉工作區裡的檔案**（例如 `名字候選.json`、`校對/段落.json`）：重算後順序會變，第 3 步做過的決定可能對不回去。漏抓的名字、段落，在第 3 步用「＋新增修改」補。
- **第 4 步開始前總檢查的「有人聲但沒有字」一定要聽**：轉文字每次都可能隨機漏掉幾段（有人講話，但逐字稿沒有字），那裡的名字工具找不到。人聲 3 秒以上的放在「一定要處理」，聽過、確定沒有提到名字（或已經在第 3 步補好名字卡）才按「我聽過了」。
- **學員段落的聲音像老師時**，第 3 步卡片與第 4 步總檢查「請看一眼」會提醒「這一段的聲音特徵有不少像老師」：請聽一下，是老師在講話就把說話者改成老師（不然老師的話會被換成學員的聲音）。
- **第 5 步標紅、標「要人聽」的一定要聽**：生成的長度跟原本差太多、切在講話中、內容檢查沒做成的，都會標出來。
- 畫面上的灰色小字（例如 `T027`、`名字 35`、`重疊 O2754.10`、`剪掉 S3`、`消音 M001`）是這一筆的編號。回報問題時把編號與原片時間一起寫，比較好找。

**流程第 1 步一次跑完**：轉文字 → 段落分析（Claude）與認老師同時跑 → 合併判斷 → 找重疊 → 挑參考音 → 找姓名 → 學員段落認人，結果都寫進工作區資料夾。Claude 叫不到時會印警告、改用純聲紋判斷繼續跑。

轉文字（0.2.0b2 起）：整支影片每約 10 分鐘一塊、原封不動送 Groq（切在離 10 分鐘最近的安靜處），不再先挖掉停頓；提示詞不帶名冊。句子斷得比較細（同一支 97 分鐘的影片，以前約 635 句，現在約 1440 句），Groq 的用量約多 1.5 倍（97 分鐘送 10 次）。轉完會在終端機印兩個統計（只有數字與時間）：

- **有人聲但沒有字**：Groq 每次都可能隨機漏掉幾段，逐字稿那裡沒有字、也找不到名字。第 4 步開始前總檢查會列出來要人聽
- **落在安靜處的字**：沒人講話的地方，Groq 偶爾會自己冒出字。只統計、不刪

已經轉好文字的工作區不會重轉。找名字（0.2.0b2 起）除了聲紋判成老師的句子，也掃判成「太短」「不確定」的句子（學員段落裡的除外）與老師段落裡判成不是老師的句子；這些新候選排在最後面。舊工作區重跑分析時只補找、加在最後面，原本的編號與決定不變（補出來的卡要在第 3 步看過，才能進第 4 步）。

- 重切出來的長度跟紀錄差超過 0.25 秒（切點換到別的停頓、逐字稿可能對不上）的那一個不換，會印出來

**用老師的 AI 聲音重念句子**（流程第 4 步的一部分）：先用 `ref use` 選定參考音，再準備一份句子清單。`.txt` 一行一句；要放回原片時間的話用 `.json`，每句附原片時間格：

```json
[{"id": "T4", "text": "如果我們從科學來看……", "slot": [5002.12, 5019.68]}]
```

```bash
.venv/bin/bookclub gen teacher ~/讀書會剪輯資料/影片/第1堂_剪輯工作區 句子.json
```

每句用固定種子 42 生成，生成完用 Groq 轉回文字檢查：念錯、漏字就換種子重來。最多試 3 次，還是不過的標「要人聽」。

有時間格的句子，會做出幾種放回時間格的版本讓人挑：**插入停頓**（用逐字對位模型找出老師原本在哪裡停頓，在生成的聲音補上空白，只補在標點的位置，落在句子中間的停頓移到最近的標點；開口時間也對齊原片）、**補靜音**（一口氣念完，後面補空白）、**拉長**（整段放慢，最多到 0.85 倍）；前面幾種長度都差超過 15% 時，才會**改語速重生成**。`slot` 有給、`text` 不給的話，會照原片那段的逐字稿念（含老師重複的字）。結果在工作區的 `生成/老師/`，紀錄在 `生成/老師紀錄.json`（格式見 `docs/工作區格式.md`）。中斷後重跑會沿用已經生成好的句子；加 `--redo` 全部重做，加 `--no-check` 不做內容檢查，加 `--no-pauses` 不做插入停頓。

**發音對照表**（`~/讀書會剪輯資料/發音對照表.csv`，欄位：`原字`、`生成用`、`原因`、`建立日期`）：模型的口音不完全是台灣口音，有些詞會念偏（例如「愉快」念成「玉快」）。把念偏的詞跟「念起來比較接近台灣口音的寫法」寫進這份表（「愉快」→「魚快」），生成前會自動替換。只影響送進模型念的文字，內容檢查、對位都還是用原本的文字；改了對照表，用到那個詞的句子下次會自動重新生成。範例在 `profile.example/發音對照表.csv`。

**處理老師提到名字的地方**（第 3 步覆核完之後）：照每筆的做法（直接消音／整句換掉／只換名字）排出計畫，需要生成的交給老師 AI 聲音，再組出新聲音軌：

```bash
.venv/bin/bookclub gen names ~/讀書會剪輯資料/影片/第1堂_剪輯工作區
.venv/bin/bookclub render audio ~/讀書會剪輯資料/影片/第1堂_剪輯工作區
```

- 覆核標成「不是名字」「是地名」的會略過；同一句有好幾個名字要整句換掉時，合成一次生成
- 生成用的句子清單只含代號，不含本名；句子裡找不到比對到的字的，列在「要人處理」
- `render audio` 從原片重新抽 48kHz 聲音，換聲音的地方音量對齊原本那段、接縫交叉淡入淡出；消音的地方墊前後 20 秒內最安靜的底噪
- 產出在工作區的 `輸出/`：`新聲音軌.wav`（跟原片等長，交給剪輯軟體換掉原本的聲音）、`處理前後.html`（每一筆處理前／處理後各前後多 2 秒的試聽，給第 5 步成品檢查）
- 測試時可以只處理幾筆：`gen names <工作區> --only 3,9,13`

- `gen students`：學員段落照句子接成 8～20 秒一段，用匿名聲線重念。聲線放在 `~/讀書會剪輯資料/聲線/候選_0928/`（`男1.wav`、`女1.wav`⋯，逐字稿同檔名 `.txt`，設定包會帶）；某個性別一個候選都沒有時，才用 `聲線/男聲_暫定.wav`、`女聲_暫定.wav`。每位學員照男女自動輪流配一個（同一集每位不同），男女照名冊性別，名冊沒有就用原音估音高；第 3 步「② 辨識學員聲音是誰」可以改。可以中斷續跑
- `render video`：換聲音（音量對齊、墊環境底噪）、刪除確認刪除的段落、比時間格長太多的學員段落停格補長、模糊示範，輸出三種做法比速度（`--methods hw,sw,smart`）。`--label` 另外輸出標字試看版：AI 處理過的時段左上角有標籤、生成的時段下方是餵給模型的文字。同時產出處理標記清單（`輸出/處理標記_<範圍>.html`），列出每一處 AI 做了什麼

**覆核工作台**（第 3 步）：`run analyze` 跑完之後開網頁第 3 步。

網頁上的處理方式統一用四個名稱：**老師重念**（用老師的 AI 聲音念一整句或一段）、**學員重念**（用匿名聲線念學員的話）、**剪掉**（聲音和畫面都拿掉，影片會變短）、**消音**（只拿掉聲音，畫面留著，墊附近的環境底噪）。

- **開始前 4 件事**（一進來先做，做完按「開始逐筆看」；之後可以從頂端回來改）：① 建議刪除段落（影片分析找到的開頭空白、結尾道別、念聊天區留言、小組討論前後、技術問題，逐段選「剪掉（連畫面）」或「不剪」）② 辨識學員聲音是誰（左邊每位「學員 N」試聽、選本名，最後一個選項是老師，旁邊顯示配到的匿名聲線、可以改；右邊每個本名在這一集用哪個代號，可以自動配）③ 辨識其他名稱如何替換（這一集提到、名冊上沒有的人名：換成代號、是上面的學員、不是名字、不用處理）④ 誰保留原聲（只有同意的學員）。做完之後，落在剪掉範圍裡的項目、保留原聲學員的學員段落自動標「不用處理」；保留原聲的學員講到名字會列成「學員提到名字」（預設直接消音，可選換成代號：用他自己的聲音重念那一句）
- 上半部：左邊影片、時間列（跳到時間、播放速度）、整支時間軸（老師灰、學員綠、冥想導讀淡藍；名字、重疊、剪掉標記）；右邊「目前這一筆」：內容、藍底的建議＋一行原因、通過／改做法／上一筆／下一筆
- **灰色小字的編號**（0.2.0b2 起，第 3、4、5 步都有）：例如學員段落 `T027`、`名字 35`、`重疊 O2754.10`、`剪掉 S3`、`消音 M001`，跟 `bookclub inspect` 的寫法一樣。回報問題、請 AI 助手查資料時用這個編號
- **只播這一段**（0.2.0b2 起）：學員段落、改成老師、剪掉、重疊、消音的卡片多一顆「只播這一段」，從這一筆的起點剛好開始播、播到終點停。名字卡沒有這顆，照舊用「只播重念範圍」。點卡片跳過去照舊從前 2 秒開始播
- **學員段落的聲音像老師時提醒**（0.2.0b2 起）：段落裡聲紋判成老師的句子佔 30% 以上、而且合計 5 秒以上，卡片上寫「這一段的聲音特徵有不少像老師⋯請聽一下：是老師在講話就把說話者改成老師」。不擋通過
- **學員段落裡的重疊不出卡**（0.2.0b2 起）：重疊落在會整段重念的學員段落裡、兩邊都沒有老師時，不出卡、自動算處理好（跟著那一段整段重念）。聽到其實是老師插話的話，到「設定」→「已自動跳過的重疊」救回
- 要念的文字裡有英文時，卡片會提醒「不是專有名詞的話，建議改成中文再生成」（不擋）
- 下半部：篩選（全部／還沒確認／學員段落／名字／學員提到名字／重疊／剪掉／消音／改成老師）＋一行一筆的清單，點一行就換到右邊
- **每一筆一開始就有建議**，看過沒問題按「通過」：學員段落的逐字稿已經把名冊上的名字換成代號（換過的字標出來），建議學員重念；老師提到名字建議老師重念那一句；重疊照規則給建議（保留原聲學員、一來一往交接、學員在老師話裡短短附和、判斷不出來→不用改；老師在學員話裡短短回應→生成學員聲音）。不重要的學員短句建議剪掉，按通過前會先問一次
- 播放完全由人控制；播到下一筆的地方，右邊自動換過去（正在打字時不換）。按「通過」只標通過、影片照常播；上一筆／下一筆讓影片跳到那筆前 2 秒
- 「改做法」展開全部做法（名字：老師重念、只換名字、直接消音，加上標記「不是名字」「是地名」「切點削到旁邊的字」；重疊：不用改、生成老師聲音、生成學員聲音、兩邊都重新生成（照原本的時間）、消音；學員段落：改說話者、併進上一段、從游標處切開、聽不清楚問老師、剪掉這段）
- **＋新增修改**（時間軸下面）：在「新增操作：」選要新增什麼（剪掉、消音、漏抓的發言〔學員，或要老師重念的話〕、漏抓的「老師提到名字」、漏抓的重疊），起點終點各一格，三種填法：直接打時間（`43:15.2`）、按「用目前播放位置」、按 ±0.1 秒微調；「試聽這段」播到終點自動停。按「新增」後時間自動對齊到小數點以下，畫面顯示「你標的 → 對齊後」：剪掉、消音對齊附近的安靜處；老師提到名字對齊逐字稿裡字的時間（前後留一點停頓，要選換成哪個代號）；發言、重疊對齊句子邊界；附近找不到可以對齊的地方就保留你標的時間、標「沒對齊」。新增的項目在清單裡標「人工新增」。已經有的項目按卡片上的「改時間」，用同一個面板改
- 快捷鍵：Enter 通過（逐字稿裡 Shift＋Enter 換行）、E 改做法、↑／↓ 上一筆／下一筆、空白鍵播放暫停、J／L 前後 5 秒、I／O 把目前時間填進「新增修改」的起點／終點、Esc（文字框裡）從頭播這一筆；頂端「快捷鍵」按鈕可以展開說明
- 頂端一行顯示進度、花了多少時間、推算整支要多久

**第 4 步「AI 執行」**（測試版）：老師提到名字 → 學員重念 → 保留原聲學員講到名字 → 組裝成品，依序跑。

網頁第 4 步最上面是 **開始前總檢查**（只讀，不改任何東西），分兩區：

- **一定要處理**：學員的話落在段落外面、名字換不了代號、要念的字數跟原本那段差太多、重疊缺文字或缺學員是誰、可能漏抓的學員發言、要念的文字裡還有舊的英文代號、**有人聲但沒有字（人聲 3 秒以上）**。有任何一列還沒處理，「開始執行」按不下去。每一列可以跳過去聽，要改的按「去第 3 步改這一筆」；段落外面、漏抓的那兩種，聽過確定沒有學員的聲音，可以勾「我聽過了，這裡沒有學員的聲音」。確認過的列顯示成灰色，可以勾「把確認好的收合起來」
- **有人聲但沒有字**（0.2.0b2 起）：這裡有人講話，但逐字稿沒有字（轉文字漏掉了），工具找不到這裡的名字。請聽一下：有提到名字，就到第 3 步用「＋新增修改」→ 漏抓的「老師提到名字」補一張名字卡（起訖填這一段時間），補好再回來；沒有提到名字，勾「我聽過了，沒有提到名字（或已經補好名字卡）」。重新分析後時間小幅移動（1 秒以內）的，之前勾的照算
- **請看一眼**：剪掉的片段、消音、超過 10 秒的老師重念、自動算處理好的（被別筆涵蓋）、預估時間與硬碟空間、記憶體；0.2.0b2 起多了：比較短（不到 3 秒）或落在會整段重念的學員段落裡的「有人聲但沒有字」、學員段落的聲音像老師、學員段落裡自動處理的重疊（每一處可以點過去聽）、要念的文字裡有英文。不擋，但要勾一次「我看過了」；之後多了新的列，要再勾一次

兩區都處理完，才按「開始執行」。終端機的 `run execute` 要組裝時也會做同樣的檢查。

**讀不到 Groq 金鑰時不讓開始**（0.2.0b2 起）：生成完要用 Groq 檢查「念對沒有」，讀不到金鑰就先不開始（網頁與終端機都一樣）。Mac 請雙擊「啟動.command」開網頁；WSL2 請確認金鑰寫在 `~/.profile`，開新的終端機再啟動。只重新組裝不需要金鑰。終端機確定不檢查也要跑時加 `--allow-no-key`，那樣每一句都會標要人聽。

```bash

```

`run execute` 依序跑：老師名字 → 學員重念 → 保留原聲學員講到名字（選了換成代號的才生成）→ 組裝（預設整段軟體編碼）。
第 3 步標的消音、保留原聲學員講到名字的直接消音，組裝時墊附近的環境底噪。學員段落其實是老師在講話時，
在第 3 步學員段落卡片上按「這段其實是老師」。

```bash
.venv/bin/bookclub gen stunames ~/讀書會剪輯資料/影片/第1堂_剪輯工作區
```

- **每一段各自一支程式跑**（10-01，8GB 的 Mac 用）：同一支程式裡換步驟、換聲線時，前一個模型佔的記憶體不一定還給系統，兩個模型疊在一起會把記憶體撐爆（10-01 夜間第一堂：系統拿硬碟頂替的量衝到 11 GB、程式沒留訊息就結束）。現在 `run execute`（網頁「開始執行」）自己不載入模型，一段一段開子程式（`bookclub run part`，平常不用自己打），那一段做完程式就結束、記憶體一定還回去；任何時候記憶體裡最多一個大模型：
  - 老師名字：「生成」（生成模型）→「插入停頓」（逐字對位模型）→「收尾」（長度還是不過才改語速重生成，要的話才載入生成模型；放回時間格、寫紀錄），各一支
  - 學員重念：每個聲線一支「生成」→ 全部聲線一支「插入停頓」（對位模型只載入一次）→ 每個聲線一支「收尾」
  - 保留原聲學員講到名字：同上，以學員分（每位用自己的聲音）
  - 組裝：一支
  - 子程式的訊息一行一行即時出現在網頁訊息列與終端機；網頁「說明」欄寫跑到第幾支。每一支結束時把記憶體高峰、swap 最高、硬碟最低記在 `生成/子程式紀錄.jsonl`（也在 `生成/執行進度.json` 每一步的「子程式」）
  - 子程式出錯：那一步標失敗，訊息帶子程式最後幾行。被系統結束、沒有錯誤訊息（多半是記憶體不夠）：訊息寫明，等 30 秒重試一次，再不行才標失敗；做好的留在快取，不重做
  - **硬碟、記憶體不夠就停**：每一支開始前、跑的過程中約每 20 秒看一次。開始前硬碟可用要 5 GB 以上；跑的過程中硬碟低於 2.5 GB、或 swap（記憶體不夠時系統拿硬碟頂替的量，只有 Mac 讀得到）高於 8.5 GB，就請它做完目前這一句再停，訊息寫明是哪一個數字、現在多少、門檻多少、怎麼處理。門檻在 `settings.toml` 的 `[thresholds]`（`execute_min_disk_gb_start`、`execute_min_disk_gb`、`execute_max_swap_gb`）
  - **跑之前先關掉瀏覽器其他分頁與用不到的程式**：10-01 夜間同時跑別的事，老師那一步平均每 1 秒聲音花 23 秒；只跑一件事 7 秒
  - 個別指令（`gen names`、`gen students`、`gen stunames`、`render video`）照舊在同一支程式裡跑完三個階段；8GB 的電腦建議用 `run execute`
- 每一步都可以中斷續跑，已經做過的跳過（名字的每一句都生成好了、範圍內學員段落都生成過且文字沒變、成品比覆核與生成結果新）；進度記在 `生成/執行進度.json`
- 開始前先檢查缺什麼（逐字稿、段落分析、老師參考音、匿名聲線、原片），缺了直接說，不會跑到一半才失敗
- 情境：老師已經自己看完全片、挑好參考聲音，想直接請 AI 做。**第 1 步轉文字還是要跑**（學員的話要照逐字稿重念，電腦自動）；**第 2 步的老師參考音要選好**、會出現的名字都要有代號（前置檢查會擋；缺代號時頁面上有「幫還沒代號的自動配」）；能省掉的是第 3 步逐筆覆核的人工，沒覆核的話照第 1 步的建議做
- 網頁第 4 步：各類「完成／總數」與「已生成 N／共 M 句」（每生成一次就更新）、預估剩餘時間；「停止」會等目前這一句生成完才停（組裝中按的話等組裝做完），做好的都留著；伺服器跑到一半被關掉，下次開會顯示「中斷」，按開始執行接著做
- 選項：`--start 37:00 --end 55:23`（只做一段）、`--methods hw,sw,smart`（組裝的輸出做法，預設 sw 整段軟體編碼；hw 硬體編碼只有 Mac、smart 只重做片段）、`--only 組裝`（只跑某幾步）、`--redo-returned`（第 5 步退回的那幾筆一起重做，見下面「成品檢查」）、`--reassemble-only`（只重新組裝，不重新生成）、`--allow-no-key`（讀不到 Groq 金鑰也照跑，每一句標要人聽）
- **只重新組裝**（0.2.0b2 起）：第 5 步退回的只需要重新組裝、不用重新生成聲音時（聲音本身沒問題，要改的是接起來的地方），按第 4 步「第 5 步退回重做的」那一區的「只重新組裝（不重新生成）」。這顆按鈕**只有第 5 步有退回的項目時才出現**；沒有退回、想照現在的程式重新組裝一次（例如更新到修過組裝的新版本），請用終端機 `.venv/bin/bookclub run execute <工作區> --reassemble-only`（按「開始執行」不會重新組裝：工具看到成品比生成結果新，就當作做過了）
- 還沒做：匯入老師的標記清單（要先確認老師標記是文字清單、網頁標記、還是剪輯軟體的標記點；參考聲音是給音檔還是時間點）

組裝（`render video`、`render audio`）做完會自動寫 **AI 處理紀錄** `生成/處理紀錄.json`：每個動作的原片起訖、成品起訖（刪除、停格之後）、做了什麼、對應第 3 步哪一筆、用了哪個檔案；並把原片聲音和新聲音每 20 毫秒比一次，列出「聲音變了、但沒有紀錄」的地方（`未登記的變動`），第 5 步要人確認。

**成品檢查**（第 5 步，09-29 原本第 5 步逐筆覆核＋第 6 步整片檢查合成一步）：版面像第 3 步，左邊成品影片＋時間軸（AI 處理過的地方全部標出來），右邊目前這一筆；最上面固定一行「沒列在時間軸上的地方＝原片沒動」。

- **逐筆看**：每一筆按「處理前」「處理後」試聽（前後各多 2 秒），按「通過」或「退回重做」（要寫原因）。0.2.0b2 起：「處理後」直接用成品影片播那一段；「處理前」播原聲，影片同步播、但靜音（試聽處理前的時間不算看過）；按「通過」後往後找下一筆還沒看的（後面都看過才回到前面），開了「只看要人聽的」就只在那幾筆裡找
- **跳到某個時間**（0.2.0b2 起）：時間列的「跳到」框打時間（例如 `38:26`，按 Enter），旁邊選這是「成品時間」還是「原片時間」；原片時間會換算成成品時間再跳
- **整片看**：記錄實際播過的地方（只算 2 倍速以下連續播的；拖過去跳過的、超過 2 倍速快轉的不算），顯示「已經看過全片的 x%」；看到問題寫一句原因、按「這裡有問題（退回重做）」，就在目前時間建一筆退回
- **沒登記的變動**另列一區，一處一處確認「沒問題」或「退回重做」
- 按「送回 AI 重做（N 筆）」寫進 `覆核/成品檢查.json`，接著到第 4 步：
  - 「第 5 步退回重做的」一區列出每一筆的原因與「按下去會怎樣」，按「**只重做退回的這幾筆（N 筆）**」：要重新生成的那幾句先清掉（舊的聲音檔留著備份）、重新生成，其他做好的不重做，最後重新組裝。要念的字和範圍都沒改的，會換一種念法；每退回一次換一次，不會回到用過的念法。「開始執行」也會一起做退回的這幾筆
  - 只需要重新組裝、不用重新生成的，按同一區的「只重新組裝（不重新生成）」（0.2.0b2 起）
  - 做完回到第 5 步，這幾筆回到「還沒看」、標「重做過」


- **全部通過、沒登記的變動都確認過、整片看過 100% 才能按「輸出成品」**（09-18 定：最後一定要有人完整看過整支），輸出成工作區 `輸出/` 底下的 `最終成品_*.mp4`

找重疊是最花時間的一步。冥想引導、導讀段落改判老師後，要掃的聲音從 2814 秒降到約 2100 秒（少 25%）。

CosyVoice 生成老師聲音（`gen teacher`，26 秒參考音）：載入模型約 1.5 分鐘；之後短句（5 秒）每 1 秒聲音約需 25–30 秒運算，長句（12–16 秒）約 11–14 秒。第一堂 4 句、5 次生成共 14 分鐘。

09-29 第一堂 37:00–55:23 實測（MacBook Air M1）：學員重念（8–20 秒一段、約 14 秒匿名聲線參考音）每 1 秒聲音約 8.5 秒運算；老師名字整句（1–8 秒的短句）約 27 秒——短句的固定開銷分攤到比較少秒數。組裝 18 分鐘的範圍：整段硬體編碼約 3 分鐘、軟體編碼約 4 分鐘、只重做有動到的片段約 30 秒。

以上是 macOS Apple Silicon、純 CPU 的數字。

**Windows 11＋WSL2 實測**（2026-09-29，Intel Core Ultra 7 270K Plus 24 核心、WSL2 分到約 15GB 記憶體、沒有 NVIDIA 顯示卡，同一支第一堂 98 分鐘）：

| 步驟 | 耗時 |
| --- | --- |
| 安裝（`install.sh`，已有 CosyVoice 模型沿用） | 4 分 26 秒，大部分是下載 |
| `models download` | 14 秒 |
| `ref pick`（含整支轉文字） | 5 分鐘（Groq 轉文字佔 73%，各段快慢不一，是 Groq 那邊排隊） |
| `run analyze` | 44.5 分鐘，其中**找重疊 43.4 分鐘**（掃 2762 秒的聲音，每 1 秒聲音約 0.94 秒運算）；轉文字 60 秒、找名字 9 秒 |
| 老師 AI 聲音 4 句（35 秒聲音） | 3 分鐘，每 1 秒聲音 4.3–7.0 秒運算（比 M1 快 3–5 倍）；載入模型 16 秒 |

WSL2 上找重疊比 M1 慢，是唯一的瓶頸（純本機運算）；聲音生成反而比 M1 快。

  - **Groq**（語音轉文字）：第 1 步轉文字、第 2 步挑參考音候選的逐字稿，會把聲音片段送到 Groq；第 4 步生成的 AI 聲音（老師重念、學員重念）會送到 Groq 轉回文字，檢查有沒有念錯（`gen teacher` 加 `--no-check` 就不送）。0.2.0b2 起，轉文字的提示詞不帶名冊（只送語助詞示範），學員名字不會跟著提示詞送出

## 9. 回報與聯絡

工具跑不動或結果怪怪的時候：

1. 先在工具資料夾裡跑 `.venv/bin/bookclub doctor`（先 `cd ~/bookclub-edit`），把**完整輸出**貼給 Claude Code。第一行會印工具版本，回報時一起附上。
2. Claude Code 會照輸出裡每一項的「修法」協助排除；WSL2 安裝過程的問題也先交給 Claude Code 排錯（見第 4 節「正式安裝」底下的 WSL2 說明）。要查工作區的數字，請 Claude Code 只用 `bookclub inspect`（見 [`docs/給AI助手-查工作區資料.md`](docs/給AI助手-查工作區資料.md)），不要讓它直接打開工作區的檔案。
3. 還是不行的話，回報時請附上：
   - 錯誤訊息全文（不要只描述「壞掉了」，截圖或整段複製貼上；網頁上的紅字、訊息列，或終端機最後 20–30 行）
   - 卡在哪一步（`doctor`／`run analyze`／`ref pick`／`serve` 的哪個階段，或網頁上哪一頁、按了哪個按鈕）
   - 跟某一筆有關的話：畫面上的**灰色編號**（例如 `T027`、`名字 35`）與**原片時間**（幾分幾秒）
   - 用的是 Mac 還是 Windows（WSL2）、大概跑了多久才出錯
   - 如果方便，加跑 `.venv/bin/bookclub doctor --smoke`（實際跑三個模型各處理一小段測試音檔；只在 Mac 上跑，WSL2 會跳過），把輸出一起附上，裡面有更詳細的錯誤訊息
4. **請不要附**：逐字稿內容、學員的名字（本名、代號對照都不要）、名冊、工作區裡的 JSON 檔、影片或聲音檔。截圖前先確認畫面上沒有逐字稿或名字。
5. 把以上資訊回報給開發者，一起討論下一步。
