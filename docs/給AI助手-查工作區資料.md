# 給 AI 助手：查工作區資料

**查工作區的資料只能用 `bookclub inspect`，不要自己讀工作區的 JSON**（不要 `cat`、`Read`、`json.load`、`jq`，也不要寫一次性的 Python 去讀）。

工作區的檔案裡有學員的逐字稿、名字、退回原因、備註，有些含身心狀況。這些字一旦印到你的工具輸出，就已經外流了；
10-01、10-02 兩天就有四次是「濾了，但沒濾乾淨」。這支指令只印時間、編號、數字、狀態，其他文字一律印成
`<文字 87 字>`／`<空>`，不認得的新欄位也一樣。

```
<工具資料夾>/.venv/bin/bookclub inspect <工作區> <主題> [選項]
# 在工具資料夾裡（cd <工具資料夾>）：.venv/bin/bookclub inspect <工作區> <主題> [選項]
```

共用選項：`--from 42:00 --to 44:00`（原片時間範圍）、`--id T003`（只看這個編號，可以給好幾次；`名字:3`、`S003`、`學員重念@10.00` 都可以）。
`--毫秒`：時間印到小數 3 位（看毫秒級的重疊，例如兩格邊界差 0.03 秒；0.2.1b1 起）。
`--重算`：只有 `名字`、`剪輯決策` 兩個主題用得到，用現在的程式重新算一次給你看，**不寫任何檔**（見下表；0.2.1b1 起）。
不給主題會列出全部主題。

## 主題

| 主題 | 印什麼 | 不印什麼 |
| --- | --- | --- |
| `檔案` | 工作區有哪些資料檔、大小、修改時間 | 內容 |
| `段落` | 段落編號、起訖、說話者代號（老師／學員N；是本名就遮掉）、內容類型、已確認、句子編號；學員的秒數與段數。學員段落另外印聲紋比例（0.2.1b1 起）：`聲紋多半是老師`（是／否）、`聲紋老師比例`、`聲紋老師句數`（老師句數／算進去的句數）、`聲紋老師秒`；判成老師的句子佔 30% 以上、而且 5 秒以上，就是第 3 步卡片與總檢查提醒「聲音特徵有不少像老師」的那幾段 | 原文、校對稿、換人依據、代號 |
| `句子` | 每一句的編號、起訖、判斷（老師／不是老師⋯）、聲紋分數 | 句子文字 |
| `字` | 範圍內幾個字、每個字的起訖、字跟字之間空超過 0.5 秒的地方（`--limit` 調列幾個）。0.2.1b1 起另外印：轉文字做法；落在安靜超過 1 秒的地方的字（整支幾個、幾處，範圍內每一處的時間）；**有人聲但沒有字**（轉文字漏掉的地方：整支幾處、人聲合計幾秒、3 秒以上幾處，範圍內每一處的起訖、人聲秒數、小段數）——第 4 步總檢查「有人聲但沒有字」那幾列就是這些 | 字本身 |
| `重疊` | 編號、起訖、長度、已自動跳過、自動處理（0.2.1b1 起：落在會整段重念的學員段落裡、第 3 步不出卡的）、兩邊的角色、第 3 步的做法與已確認 | 老師／學員文字、備註 |
| `名字` | 候選編號、起訖、做法、已確認、標記（不是名字／是地名）、老師整段；上次排的名字處理計畫（生成編號、時間格、候選編號）。`--重算`（0.2.1b1 起，不寫檔）：用現在的程式在「太短」「不確定」的句子與老師段落裡判成不是老師的句子重找名字，列出現有候選沒有的那幾處時間點、句子編號、來源、比對層級 | 名字、整句、代號、改稿、備註 |
| `消音` | 局部消音、剪掉的片段、建議剪掉：編號、起訖、方式、狀態、決定 | 備註、建議的原因 |
| `總檢查` | 第 4 步開始前總檢查每一列：鍵、起訖、已按聽過、新的、第 3 步卡片；有成品時附成品時間。學員段落像老師的那幾列另印聲紋數字（0.2.1b1 起） | 說明、名稱、怎麼改 |
| `生成` | 老師／學員／保留原聲的每一句：時間格、選定第幾次、要人聽與原因類別（內容沒通過、念對沒有的檢查沒做成、漏了一串字⋯、放回時間格差太多、切在講話中、其他原因）、放回做法、差異比例、第幾版、聲音檔在不在；學員每一格另印切在講話中是不是與切點、現在的段落排出來的時間格與跟紀錄差幾秒；每次嘗試的種子、語速、長度、內容分數、通過與否；以前的版本與避開的種子（`--who 老師`） | 要念的字、轉回文字、檔案路徑、不是固定說法的內容問題 |
| `子程式` | 第 4 步每一支子程式：名稱（固定格式才印）、秒數、結束碼、記憶體高峰 | 參數（只印個數） |
| `成品檢查` | 第 5 步處理紀錄每一筆：鍵、類型、原片／成品起訖、通過／退回、有沒有寫原因、改範圍改成；沒登記的變動、整片退回（`--要人聽` 只列要人聽的） | 原因、做了什麼、文字、檔案 |
| `剪輯決策` | 組裝排出的動作（類型、編號、起訖、放回做法、加快、停格秒、被蓋過改消音是哪一類）、剪掉、停格、標記、每一筆警告的類型、涉及的動作編號、起訖（小數 3 位；0.2.1b1 以前組裝的檔沒有明細，從警告開頭的編號推算）、成品長度（`--tag <名稱>` 指定哪一份；`--重算` 用現在的程式重新排一次，不組裝、不寫檔） | 文字、警告的內容 |
| `換算` | `--原片 42:59.8` → 成品時間、`--成品 38:26.4` → 原片時間（可以給好幾個；`--tag` 指定哪一份剪輯決策，不給用第 5 步那一份處理紀錄） | — |
| `前後沒聲音` | 老師重念範圍前後沒有字的那幾筆：時間格、前後各幾秒、建議範圍、能不能一鍵縮 | — |
| `底噪` | 全片底噪挑到哪一段、音量、確認了沒有、候選 | — |
| `代號` | 這一集用到的代號與各幾個人用、自動配（人沒改過）的代號個數（只印名單上的代號）與開始前 ③ 自動配過沒有、還在用的英文代號與建議的中文、要念的文字裡還有舊英文代號的地方（新舊代號名單上的代號照印） | 本名、自己打的代號、文字 |

## 範例

```
bookclub inspect <工作區> 成品檢查 --要人聽
bookclub inspect <工作區> 生成 --who 老師 --from 42:50 --to 43:10
bookclub inspect <工作區> 字 --from 42:59 --to 43:08
bookclub inspect <工作區> 換算 --原片 1:17:23.3 --成品 1:29:04
bookclub inspect <工作區> 總檢查
bookclub inspect <工作區> 名字 --id 名字:12
bookclub inspect <工作區> 名字 --重算
bookclub inspect <工作區> 段落 --id T027
bookclub inspect <工作區> 剪輯決策 --重算 --毫秒
```

## 規則

- 原片 ↔ 成品時間**只用 `換算`**（或程式的 `render.to_output_time`）。不要自己扣剪掉的片段：停格也要算進去，10-02 有人自己算差了 13 秒
- 這支指令不寫任何檔（執行期間把存檔換成不寫的版本），可以放心對複本或正式工作區跑
- 需要的資訊這裡沒有：先問使用者，或在 `bookclub/safeview.py` 加欄位（數字、編號、固定說法才加進白名單），不要繞過去讀 JSON
- 網頁畫面上也有逐字稿與名字：用瀏覽器工具驗畫面時，只查要驗的元素，不要把整頁文字抓回來
