## 霧化（局部消音、學員名字消音的另一種方式）

`覆核決定.json` 的局部消音 `方式` 可以選「霧化」，但組裝時還是墊底噪（處理紀錄註明「霧化還沒做，先墊底噪」）。
要做的：用濾波器讓人聲變得霧霧的，聽得出處理過、不影響理解；**用在名字或敏感內容時要確認聽不出字**——霧化後丟 Groq 轉文字，
轉得出名字就不合格，退回墊底噪並列在報告裡。（12 任務單任務 4，有餘力才做，這輪沒做）

## 移植到 Windows 要注意（09-29 宇軒：現在在 Mac 測，之後夥伴在 Windows 跑）

| 地方 | Mac 現在 | Windows 要怎麼辦 |
| --- | --- | --- |
| 輸出做法 | 預設整段軟體編碼（libx264） | 一樣，結果相同 ✓ |
| 硬體編碼 `hw` | `h264_videotoolbox`（Mac 才有） | 要看顯示卡：NVIDIA `h264_nvenc`、Intel `h264_qsv`、AMD `h264_amf`，各自實測；沒有就不能用 |
| 只重做片段 `smart` | 用 AVFoundation 接片段（`bookclub/avconcat.swift`，Mac 才有） | 退回 ffmpeg 接：QuickTime 確定解不了，Windows 的播放器、剪輯軟體要實測 |
| QuickTime 相容檢查 | `avconvert` | 沒有這個指令，自動跳過（驗證結果記 `null`） |
| Groq 金鑰 | 放 `~/.zshrc`，要用 `zsh -ic` 啟動 | WSL2 的 bash 放 `~/.bashrc`；原生 Windows 用系統環境變數 |
| 防睡眠 | `caffeinate`／App 的保持喚醒 | `powercfg` 或電源設定（要夥伴自己設） |
| 路徑 | 中文路徑沒問題 | ffmpeg、Python 都要實測中文路徑（WSL2 掛 Windows 磁碟時尤其） |
| 字型 | 標字版用 STHeiti | Windows 用微軟正黑體（`msjh.ttc`），`render.FONT_CANDIDATES` 要加 |
