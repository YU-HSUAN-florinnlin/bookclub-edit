# bookclub-edit Skill

## 用途

工作夥伴對 Claude Code 說「幫我處理這支讀書會影片」時的對話入口。這個 skill 只負責
**確認環境、啟動本機網頁**，實際的分析、覆核、聲音生成、成品檢查全部在瀏覽器裡完成——
不在對話裡進行。

## 工具資料夾在哪

工具資料夾＝這份 SKILL.md 往上兩層（`skills/bookclub-edit/` 的上上層）。`~/.claude/skills/bookclub-edit`
是安裝時建的捷徑，實際位置用這行查：

```bash
readlink ~/.claude/skills/bookclub-edit    # 印出 <工具資料夾>/skills/bookclub-edit
```

README 的例子用 `~/bookclub-edit`，夥伴放在別的位置時照查到的換掉。下面寫 `<工具資料夾>` 的地方都換成實際位置。
`.venv/bin/...` 開頭的指令都要先 `cd <工具資料夾>` 再跑。

## 平常怎麼操作（0.2.0b2）

1. **啟動**：macOS 雙擊工具資料夾裡的「啟動.command」，瀏覽器會自動開 <http://localhost:8766>。
   WSL2 在終端機跑 `cd <工具資料夾> && .venv/bin/bookclub serve`，再請夥伴用 Windows 的瀏覽器開
   <http://localhost:8766>（WSL2 不會自動開瀏覽器，終端機會印出網址；網頁在 WSL2 上還沒實測）。
   伺服器記得上次在做哪支影片，重開後自動接回。
2. **總覽選影片**：在網頁內的資料夾瀏覽選影片，按「開始分析」。會在影片旁邊建
   `<影片檔名>_剪輯工作區/`；同一支影片做到一半的，會接著做。已有的專案點「切換」。
   網頁只能選家目錄底下的影片：WSL2 要先把影片從 `/mnt/c/...` 複製到 `~/讀書會剪輯資料/影片/`（README 第 3 節
   「WSL2：影片放進去、成品拿出來」）。
3. **照左側步驟列走 0～5 步**（每步標 AI 或人工）：

   | 步驟 | 誰做 | 做什麼 |
   |---|---|---|
   | 0 初始化設定 | 人工 | 名冊、敏感詞、名字排除清單、發音對照表、匿名聲線（學員重念用）；設定包匯出匯入（第一次才要，設定包裡含匿名聲線） |
   | 1 影片分析 | AI | 轉文字、認老師、找重疊、挑參考音、找名字、段落分析、建議刪除段落 |
   | 2 挑選老師參考聲音片段 | 人工 | 聽候選（「聽上一個」「聽下一個」）、改逐字稿、按「改用這一個」；已選定的那一個按「存逐字稿（音檔不換）」 |
   | 3 覆核工作台 | 人工 | 先做「開始前 4 件事」（① 建議刪除段落 ② 辨識學員聲音是誰 ③ 辨識其他名稱如何替換 ④ 誰保留原聲），再逐筆通過 |
   | 4 AI 執行 | AI | 先過「開始前總檢查」（「一定要處理」全部處理完、「請看一眼」勾「我看過了」），再按「開始執行」：老師名字 → 學員重念 → 保留原聲學員的名字 → 組裝；可以按「停止」，下次接著做。讀不到 Groq 金鑰時不讓開始 |
   | 5 成品檢查 | 人工 | 逐筆看＋整片看過 100%，全部通過才能輸出成品 |

   第 4 步跑的時候第 3 步只能看、不能改；電腦不要睡眠（Mac 工具會自己防閒置睡眠，但闔上螢幕還是會睡；
   Windows／WSL2 沒有防睡眠，要先照 README「Windows：跑之前先把電腦設成不睡眠」設好）。第 5 步退回的項目，按「送回 AI 重做」後到第 4 步按
   「只重做退回的這幾筆」（或「開始執行」），只重新生成退回的那幾句、再重新組裝；聲音沒問題、只需要重新組裝的，
   按同一區的「只重新組裝（不重新生成）」。這一區只有第 5 步有退回時才出現；沒有退回、想重新組裝時用
   `.venv/bin/bookclub run execute <工作區> --reassemble-only`。做完回到第 5 步，這幾筆回到「還沒看」。

   **這一版要特別提醒夥伴的**（細節見 README「怎麼用」的「每一步要特別注意的」）：
   - 這一版只處理聲音與說出口的名字，不處理畫面（學員的臉、Zoom 姓名標籤還在）
   - 第 4 步總檢查的「有人聲但沒有字」（轉文字漏掉的地方）一定要聽：有提到名字就到第 3 步「＋新增修改」補名字卡，
     沒有才按「我聽過了」
   - 第 3 步卡片或總檢查提醒「這一段的聲音特徵有不少像老師」：聽一下，是老師就把說話者改成老師
   - 第 3 步做過之後，不要為了重跑第 1 步去改名或刪掉工作區裡的檔案（第 3 步的決定可能對不回去）
   - 畫面上的灰色小字（`T027`、`名字 35`⋯）是編號；夥伴回報問題時請他一起說編號與原片時間
   - 第一次處理一支影片請預留 12 小時；第 1 步約 45 分鐘、第 4 步約 3–4 小時可以離開，其他是人工
   網頁上的處理方式叫「老師重念」「學員重念」「剪掉」（連畫面）「消音」（只拿掉聲音），跟夥伴說明時用一樣的名稱。

## 觸發時機

- 夥伴說「幫我剪讀書會」「處理第 N 週影片」「讀書會影片隱私處理」
- 夥伴提供一個影片路徑，說要處理（換聲音、換名字）
- 夥伴說環境好像有問題、貼出 `bookclub doctor` 的錯誤訊息

## 執行流程（Claude Code 這邊做的事）

1. **環境還沒裝好時**：程式還沒下載的話，照 README 第 4 節「下載程式」用 `git clone` 下載。
   在工具資料夾裡先跑 `bash install.sh --check-only`，看電腦裡已經有哪些工具與模型
   （別處已經裝過的 CosyVoice 與模型會被認出來、直接沿用，不重抓約 7GB）。再跑 `bash install.sh`
   安裝缺的部分。裝完會自動跑一次 `bookclub doctor`，把結果念給夥伴聽，必要項目沒過的照畫面上的「修法」處理。
2. **確認環境沒問題**：跑 `.venv/bin/bookclub doctor`，必要項目全過才繼續。常見還沒處理的項目：
   - Hugging Face 還沒登入 → 照畫面上的三步驟說明處理
   - GROQ_API_KEY 還沒設定 → macOS 加到 `~/.zshrc`；WSL2 加到 `~/.profile`（不是 `~/.bashrc`，工具讀不到），開新終端機視窗
   - claude 指令找不到（WSL2 常見）→ WSL2 裡另外裝 Claude Code 並登入一次，不然段落分析會失敗
3. **請夥伴照上面「平常怎麼操作」走**：雙擊啟動、總覽選影片。影片路徑不用在對話裡給。
4. **出問題時**：請夥伴貼 `bookclub doctor` 的完整輸出，或網頁上紅色橫幅／失敗訊息的文字，照「修法」處理；
   處理不了的，把輸出貼給 Claude Code 討論。
5. **要更新到新版本時**：照 README 第 4 節「更新到新版本」：每個新版本整個重新下載一次，不在舊資料夾上
   `git pull`。步驟：停掉網頁 → 舊資料夾改名成 `bookclub-edit-舊版` → `git clone` 回原本的位置 → `bash install.sh`
   → 開網頁確認「總覽」看得到原本的專案 → 用過一陣子沒問題再刪舊版。`~/讀書會剪輯資料/`、影片旁邊的工作區、
   `~/.cache/` 底下的模型、各種登入與金鑰都不在工具資料夾裡，不受影響。位置要跟原本一樣，skill 捷徑才不會指到舊版。

終端機指令（`bookclub run analyze`、`run execute`、`gen teacher`、`render video` 等）是測試與除錯用的，
用法見 README 第 5 節；平常操作都在網頁上。

## 環境健檢（bookclub doctor）

```bash
cd <工具資料夾>
.venv/bin/bookclub doctor            # 一般檢查（最後會印出現在用的原始碼與模型在哪裡）
.venv/bin/bookclub doctor --smoke    # 加碼：實際跑三個模型各處理一小段測試音檔（幾分鐘）
.venv/bin/bookclub doctor --claude   # 加碼：實際呼叫一次 claude -p 測試有沒有反應
```

## 隱私提醒

老師的名冊、聲音樣本、影片放在 `~/讀書會剪輯資料/` 與影片旁邊的工作資料夾，不在這個倉庫裡。
要查工作區的狀態時，**只能用** `.venv/bin/bookclub inspect <工作區> <主題>`（只印時間、編號、數字、狀態，說明在
`docs/給AI助手-查工作區資料.md`），不要直接打開工作區的 JSON、逐字稿（不要 `cat`、`Read`、`jq`、自己寫 Python 讀）。
需要的數字 inspect 沒有，先問夥伴，不要繞過去讀檔。
Claude Code 討論時不要把名冊內容、學員逐字稿細節貼進對話（跟主要工作環境的個資分級規則一致：
🟡 聯絡資料、🔴 學員諮詢內容不給 AI 原文）。
