# bookclub-edit Skill

## 用途

工作夥伴對 Claude Code 說「幫我處理這支讀書會影片」時的對話入口。這個 skill 只負責
**確認環境、啟動本機網頁**，實際的分析、覆核、聲音生成、成品檢查全部在瀏覽器裡完成——
不在對話裡進行。

## 平常怎麼操作（0.1.8 之後）

1. **啟動**：雙擊工具資料夾裡的「啟動.command」（macOS）；WSL2 在終端機跑
   `cd ~/Downloads/bookclub-edit && .venv/bin/bookclub serve`。瀏覽器會開 <http://localhost:8766>。
   伺服器記得上次在做哪支影片，重開後自動接回。
2. **總覽選影片**：在網頁內的資料夾瀏覽選影片，按「開始分析」。會在影片旁邊建
   `<影片檔名>_剪輯工作區/`；同一支影片做到一半的，會接著做。已有的專案點「切換」。
3. **照左側步驟列走 0～5 步**（每步標 AI 或人工）：

   | 步驟 | 誰做 | 做什麼 |
   |---|---|---|
   | 0 初始化設定 | 人工 | 名冊、敏感詞、名字排除清單、發音對照表；設定包匯出匯入（第一次才要） |
   | 1 影片分析 | AI | 轉文字、認老師、找重疊、挑參考音、找名字、段落分析、建議刪除段落 |
   | 2 挑選老師參考聲音片段 | 人工 | 聽候選、改逐字稿、按「用這段」 |
   | 3 覆核工作台 | 人工 | 先做「開始前 4 件事」（① 建議刪除 ② 學員是誰 ③ 其他名字 ④ 誰保留原聲），再逐筆通過 |
   | 4 AI 執行 | AI | 老師名字 → 學員重念 → 保留原聲學員的名字 → 組裝；可以按「停止」，下次接著做 |
   | 5 成品檢查 | 人工 | 逐筆看＋整片看過 100%，全部通過才能輸出成品 |

   第 4 步跑的時候第 3 步只能看、不能改；電腦不要睡眠。第 5 步退回的項目，目前要照第 4 步頁面
   列的指令手動重做（一鍵只重做還沒做好）。

## 觸發時機

- 夥伴說「幫我剪讀書會」「處理第 N 週影片」「讀書會影片隱私處理」
- 夥伴提供一個影片路徑，說要處理（換聲音、換名字）
- 夥伴說環境好像有問題、貼出 `bookclub doctor` 的錯誤訊息

## 執行流程（Claude Code 這邊做的事）

1. **環境還沒裝好時**：先跑 `bash install.sh --check-only`，看電腦裡已經有哪些工具與模型
   （別處已經裝過的 CosyVoice 與模型會被認出來、直接沿用，不重抓約 7GB）。再跑 `bash install.sh`
   安裝缺的部分。裝完會自動跑一次 `bookclub doctor`，把結果念給夥伴聽，必要項目沒過的照畫面上的「修法」處理。
2. **確認環境沒問題**：跑 `.venv/bin/bookclub doctor`，必要項目全過才繼續。常見還沒處理的項目：
   - Hugging Face 還沒登入 → 照畫面上的三步驟說明處理
   - GROQ_API_KEY 還沒設定 → macOS 加到 `~/.zshrc`；WSL2 加到 `~/.profile`（不是 `~/.bashrc`，工具讀不到），開新終端機視窗
   - claude 指令找不到（WSL2 常見）→ WSL2 裡另外裝 Claude Code 並登入一次，不然段落分析會失敗
3. **請夥伴照上面「平常怎麼操作」走**：雙擊啟動、總覽選影片。影片路徑不用在對話裡給。
4. **出問題時**：請夥伴貼 `bookclub doctor` 的完整輸出，或網頁上紅色橫幅／失敗訊息的文字，照「修法」處理；
   處理不了的，把輸出貼給 Claude Code 討論。

終端機指令（`bookclub run analyze`、`run execute`、`gen teacher`、`render video` 等）是測試與除錯用的，
用法見 README 第 5 節；平常操作都在網頁上。

## 環境健檢（bookclub doctor）

```bash
cd ~/Downloads/bookclub-edit
.venv/bin/bookclub doctor            # 一般檢查（最後會印出現在用的原始碼與模型在哪裡）
.venv/bin/bookclub doctor --smoke    # 加碼：實際跑三個模型各處理一小段測試音檔（幾分鐘）
.venv/bin/bookclub doctor --claude   # 加碼：實際呼叫一次 claude -p 測試有沒有反應
```

## 隱私提醒

老師的名冊、聲音樣本、影片放在 `~/讀書會剪輯資料/` 與影片旁邊的工作資料夾，不在這個倉庫裡。
Claude Code 討論時不要把名冊內容、學員逐字稿細節貼進對話（跟主要工作環境的個資分級規則一致：
🟡 聯絡資料、🔴 學員諮詢內容不給 AI 原文）。
